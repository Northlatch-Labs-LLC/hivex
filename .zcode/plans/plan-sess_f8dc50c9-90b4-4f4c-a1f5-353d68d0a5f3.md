## Phase 4 — THE HEART (the exact enterprise proposal, built INTO the tested harness)
11. **Turn Engine v2** (internal/team): the turn becomes an explicit, persisted, crash-resumable state machine — INTAKE → POLICY_GATE → CONTEXT_ASSEMBLY → DISPATCH → EXECUTE → VERIFY → DISTILL → SETTLE — evolving the shipped substrate (task_verification.go gate, context_assembler.go, task_ledger.go journal, task_distill.go AppendVerified): INTAKE adds structured task fields (goal/deliverables/success_criteria mapped onto the machine-verification gate); POLICY_GATE runs default-deny capability checks BEFORE any tool dispatch; CONTEXT_ASSEMBLY stays relevance-budgeted (existing) + gains upstream dependency-outcome injection (U3.2) + living task briefs (U3.3) + Memanto retrieval; DISPATCH routes inference via the HIVEX openai-compat provider pointed at HiveAPI (Monthly entitlement pins it); EXECUTE runs tools through the fixed teammcp surface with existing worktree isolation; VERIFY = existing gate, failure re-enters the next packet; DISTILL = existing deterministic hook now also writing structured memories to Memanto; SETTLE journals the turn + emits the Stripe Meter event (Free-cap enforcement point) + requeues the scheduler. Every transition audited; office restart mid-turn loses nothing.
12. **Approval/policy engine — default-deny capability grants:** a declared capability registry (exec.bash, fs.write, net.http.get/post, integration.<platform>.<action>, memory.write, spend.*) — no capability reachable without an explicit grant {agent, capability, scope(channel/task/resource), expiry, granted_by}, exact-match, fail-closed, revocable — generalizing the shipped actionGrant model (broker_action_grants.go, deterministic-integrations.md slices 5a/5b) from integrations to ALL tool surfaces, evaluated at POLICY_GATE. Policies are data (single atomic rules compiled from playbooks + human feedback). Risk tiers: read-only auto-proceed (audited); reversible-mutating → grant or approval; irreversible/external → human inbox ceremony (existing SSE inbox). Every decision lands in the append-only audit ledger.
13. **Memory semantics — Memanto:** vendor the provided memanto zip (license verified first), Dockerfile for self-host; new backend `memanto` (HIVEX_MEMORY_BACKEND=memanto, replacing every "nex" backend reference); write path ONLY from the DISTILL hook (verification-gated, update-first: retrieve-before-write, prune/extend); read path: hybrid retrieval at CONTEXT_ASSEMBLY with "context I used" transparency; two tiers: private per-agent KG → notebooks, team KG → wiki (permissioned boundary, per core-loop.md doctrine).
14. **The Office:** structured intake (office-hours interview fields on task create), task board surface, evidence surfaces on done (already partly shipped as VerificationBadge), inbox ceremony collapse per U5.3 (merge Issue/first-action approvals; reserve the inbox for irreversible/external), TUI + web surfaces updated for the new engine states; office evals (evals/office + internal/team/office_eval.go) extended to assert the new TurnState machine and kept GREEN as the regression gate.
